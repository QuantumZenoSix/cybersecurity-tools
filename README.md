# Cybersecurity Tools

A collection of cybersecurity tools, experiments, and learning projects focused on network security, penetration testing, and security research.

This repository brings together projects I've built, explored, or used while learning about security concepts and experimenting with different tools and techniques. Each project lives in its own directory and has its own scope and requirements.

## Projects

| Project | Description |
| --- | --- |
| [angr-concolic-demo](./angr-concolic-demo/) | Demonstrates concolic execution and symbolic analysis using angr. |
| [arp-spoof-detector](./arp-spoof-detector/) | Experiments with detecting ARP spoofing activity on a network. |
| [arp-spoofer](./arp-spoofer/) | An ARP spoofing experiment for exploring local network behavior. |
| [arp-spoofer-guided](./arp-spoofer-guided/) | A guided variation of the ARP spoofing project. |
| [bettercap-arp-spoofer](./bettercap-arp-spoofer/) | An ARP spoofing project involving Bettercap. |
| [c-cypher](./c-cypher/) | A C-based cryptography or cipher project. |
| [dir-buster](./dir-buster/) | A tool or experiment for discovering directories and paths on web servers. |
| [login-bruteforcer](./login-bruteforcer/) | An experiment involving automated login attempts. |
| [mac-changer](./mac-changer/) | A utility for changing a network interface's MAC address. |
| [pcap-cracker](./pcap-cracker/) | A packet-capture-related security experiment. |
| [pcap-cracker-python](./pcap-cracker-python/) | A Python implementation or variation of the packet capture project. |
| [ransomware-single-file-lock](./ransomware-single-file-lock/) | An experiment exploring single-file encryption and ransomware-related concepts. |
| [reverse-shell](./reverse-shell/) | An experiment exploring reverse-shell communication. |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/QuantumZenoSix/cybersecurity-tools.git
cd cybersecurity-tools
```

Choose a project and follow its instructions. Dependencies, setup steps, and usage vary by project, so check the files in the relevant directory before running anything.

## Security & Responsible Use

_(gotta throw a little disclaimer in here)_

These projects are intended for educational purposes, security research, and authorized testing (they aren't necessarily production-ready).

Some tools demonstrate techniques that can affect network traffic, interact with remote systems, or modify system behavior. Use them only in environments you own or have explicit permission to test.

- Understand what a tool does before running it.
- Use isolated lab environments when appropriate.
- Obtain authorization before testing systems or networks.
- Be mindful of the potential impact on other systems and users.
